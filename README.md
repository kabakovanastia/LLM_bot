# 🤖 Telegram AI Data Analyst Bot

Телеграм-бот, который использует агента на базе Google Gemini для автоматического анализа данных. Вы отправляете CSV или Excel файл, задаете вопрос на естественном языке, а бот проводит полноценный анализ, пишет Python-код, вычисляет метрики и строит графики.

## ✨ Возможности

- **Полноценный агентный анализ**: LLM не просто описывает данные, а выступает в роли аналитика, который **сам пишет и исполняет код**.
- **Поддержка форматов**: CSV и Excel.
- **Визуализация**: Автоматическое построение графиков `matplotlib` по текстовому запросу.
- **Естественный язык**: Вы можете задавать вопросы так, как формулируете их для живого аналитика. Можете вместе с файлом или после его загрузки написать инструкцию, на что конкретно обратить внимание.
- **Защита от инъекций**: В системном промпте агента жестко заданы границы его компетенций. Любые попытки заставить бота сменить роль, выполнить системные команды или выйти за рамки анализа данных блокируются.
- **Удобный интерфейс**: Взаимодействие через Telegram-бота.

## 🛠️ Как это работает

1.  **Загрузка данных**: Пользователь отправляет боту файл `.csv` или `.xlsx`.
2.  **Постановка задачи**: Пользователь пишет текстовый запрос (например, "Сделай сводный анализ", "Найди корреляции между возрастом и доходом", "Построй гистограмму по колонке 'price' и опиши распределение").
3.  **Результат**: Бот отправляет пользователю текстовый отчет с выводами и все построенные графики в виде изображений. Длинные сообщения автоматически разбиваются на части.

## 📦 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/kabakovanastia/LLM_bot
cd LLM_bot
```

### 2. Настройка окружения

Создайте файл `.env` в корне проекта и добавьте в него ваши токены:

```env
TELEGRAM_TOKEN=ваш_токен_телеграм_бота
GEMINI_API_KEY=ваш_ключ_api_google_gemini
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

### 3. Запуск

```bash
python main.py
```

После запуска в консоли появится сообщение `Бот запущен...`, и бот начнет обрабатывать сообщения в Telegram.

## 💡 Примеры запросов

-   **Базовый анализ**: "Сделай общий анализ датасета"
-   **Анализ с контекстом**: "Проанализируй данные о продажах и обрати особое внимание на выбросы в колонке Amount"
-   **Поиск взаимосвязей**: "Найди корреляции между всеми числовыми колонками и покажи самую сильную на графике"
-   **Группировка и статистика**: "Посчитай средний чек по каждой категории товаров Category и выведи топ-3"
-   **Визуализация**: "Построй график распределения для колонки Age и ящик с усами для колонки Income"
